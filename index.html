Spotify API Setup

You need a Spotify Developer App Client ID to generate playlists.

1. Go to Spotify Developer Dashboard
2. Create an app
3. Add as a Redirect URI
4. Check "Web API" in the settings
5. Copy the Client ID and paste it here
